# My agent: Trip Planner Agent
One-liner: A conversational agent that helps travelers plan and customize personalized travel itineraries with a catalog of curated destinations, activities, and local spots.

Tool coverage:
- Memory: Traveler profile and preferences (budget tier, pacing/style, dietary needs, preferred vibes, companions, past trips)
- Tools: Search attractions and dining options, save/remove items to an itinerary, check destination weather and time
- Catalog/UI: Destinations, curated attractions, dining spots, and day-by-day trip schedules rendered as A2UI cards and tables
- Image gen: Generates scenic destination postcards and mood boards for planned itinerary stops
- Sandbox: Trip budget breakdown, currency conversion, and itinerary time/distance calculations

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for budget math and currency conversion, Google Maps / Places API integration, Cloud Trace for observability
